
# Personal Portfolio Website

## Project Description
A personal portfolio webpage created using HTML5 and an external CSS stylesheet.

## Technologies Used
- HTML5
- CSS3
- Google Fonts

## Features
- Semantic HTML structure
- Styled navigation bar with hover effects
- About, Projects, Skills, and Contact sections
- Technical skills table with alternating row colors
- Contact form with labels and validation
- Consistent color theme and custom typography
- CSS box model with margins, padding, and borders
- Sticky navigation and fixed back-to-top button
- Smooth scrolling and responsive design

## Project Files
- index.html
- style.css
- profile.jpg

## How to Run
Open index.html in a web browser.
